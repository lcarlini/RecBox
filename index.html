Screen recording for Windows — without the OBS complexity.

RecBox is a lightweight, Windows-only screen recorder focused on one job: capture a monitor at native resolution, with optional microphone and system audio, then get out of the way. No streaming. No scenes. No filters.

Features

Minimize to tray

Hide RecBox from the taskbar while recording so the app itself never appears in your video — just like OBS.

Native monitor capture

Pick any display. Recordings use that monitor’s native resolution with no unnecessary scaling.

Mic + system audio

Enable microphone and computer audio independently. NVIDIA Broadcast shows up as a normal mic when installed.

Simple quality presets

Choose Low file size, Balanced, or Maximum quality. RecBox picks hardware encoding when available.

Video only

No streaming, editing, or plugin maze — just reliable MP4 recordings you can share or edit elsewhere.

Lightweight stack

Native Windows UI with FFmpeg for capture/encode and Windows WASAPI for reliable audio.

System requirements

  • OS: Windows 10 or Windows 11 (64-bit)
  • .NET: .NET 8 Desktop Runtime (included if you publish self-contained)
  • FFmpeg: ffmpeg.exe placed in tools/ffmpeg or available on your PATH (used for video capture/encoding)
  • Optional: NVIDIA, AMD, or Intel GPU for hardware-accelerated H.264 encoding
  • Optional: NVIDIA Broadcast (appears as a microphone input device)

Installation

From source (developers)

  1. Install the .NET 8 SDK.
  2. Clone or download this repository.
  3. Download FFmpeg into tools/ffmpeg:
powershell -ExecutionPolicy Bypass -File tools/download-ffmpeg.ps1
  1. Build and run:
dotnet build RecBox.slnx -c Release
dotnet run --project src/RecBox/RecBox.csproj -c Release
You can also drop any recent Windows ffmpeg.exe into tools/ffmpeg manually. See tools/ffmpeg/README.md for details.

First launch

  • RecBox opens a single settings window — pick your monitor, audio options, and quality.
  • Recordings are saved under Videos\RecBox by default (changeable in Settings).
  • Settings persist in %AppData%\RecBox\settings.json.

How to record — step by step

  1. Choose a monitor. In Settings, open the Monitor list and select the display you want to capture. The resolution shown is the native size that will be recorded.
  2. Select a microphone (optional). Turn on Record microphone and pick Default Windows microphone, a specific device, or NVIDIA Broadcast if installed.
  3. Enable system audio (optional). Turn on Record system audio to capture what your computer plays (games, browsers, meetings). This is independent from the microphone.
  4. Pick a quality preset.
    • Low file size — smaller files, still watchable
    • Balanced — everyday default
    • Maximum quality — best looking, largest files
  5. Set the output folder if you do not want the default Videos\RecBox location.
  6. Click Start recording. The timer starts. When finished, click Stop recording (or use the tray menu).
  7. Open folder to jump to your new MP4 file.

Minimize to the system tray

While recording, you usually do not want RecBox visible in the capture. Minimize the window (or click the window close button) to send RecBox to the system tray next to the clock. It disappears from the taskbar but keeps recording in the background.

  • Double-click the tray icon to show the window again.
  • Right-click the tray icon for Show, Start/Stop recording, or Exit.
  • Use Exit in the tray menu when you want to fully quit RecBox.

Troubleshooting

FFmpeg was not found

Place ffmpeg.exe in tools/ffmpeg, run tools/download-ffmpeg.ps1, or add FFmpeg to your system PATH. Restart RecBox afterward.

No microphone / NVIDIA Broadcast missing

Confirm the device works in Windows Sound settings. Broadcast only appears after NVIDIA Broadcast is installed and its virtual microphone is enabled. Refresh by restarting RecBox.

System audio is silent

Ensure Record system audio is checked and that sound is playing through your default playback device. RecBox uses Windows WASAPI loopback, so no Stereo Mix or virtual cable is required. Some exclusive-mode apps can still block loopback — try shared mode or set another output as default.

Black screen when capturing a game or protected window

Some fullscreen exclusive games and DRM-protected content block desktop capture. Try borderless windowed mode. Capturing elevated (Administrator) windows may require running RecBox as Administrator too.

Recording failed to start / encoder errors

RecBox prefers hardware encoders (NVENC → Quick Sync → AMF) and falls back to software x264. Update GPU drivers, or switch to the Balanced / Low preset. RecBox also falls back from GPU desktop capture to a compatibility mode automatically when needed.

Where are my files?

By default: %UserProfile%\Videos\RecBox. Use Open folder in the app, or check the path shown under the timer after you stop.
