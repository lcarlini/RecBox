RecBox

Screen recording for Windows — without the OBS complexity. Capture a monitor at native resolution, with optional mic and system audio. No streaming. No scenes. No clutter.

Features

Minimize to tray

Hide from the taskbar while recording so RecBox never appears in your video.

Native monitor capture

Pick any display. Output matches that monitor’s real resolution — no scaling.

Mic + system audio

Toggle each independently. NVIDIA Broadcast shows up as a normal mic when installed.

Simple quality presets

Low file size, Balanced, or Maximum quality — with hardware encode when available.

Modern desktop UI

Clean dark interface with a one-click record control. Settings save automatically.

Easy to run

One PowerShell script downloads FFmpeg, builds, and launches. Or publish a portable folder.

Install & update

Installers place RecBox under %LocalAppData%\Programs\RecBox (no admin), create Start Menu shortcuts, and bundle FFmpeg. Your settings stay in %AppData%\RecBox across upgrades.

Setup.exe

Download RecBox-*-Setup.exe from GitHub Releases and run it. New versions: run the newer Setup — settings are preserved.

Zip + PowerShell installer

powershell -ExecutionPolicy Bypass -File .\Install-RecBox.ps1 -FromZip .\RecBox-1.0.0-win-x64.zip -DesktopShortcut -Launch

Or install/update from the latest GitHub Release:

powershell -ExecutionPolicy Bypass -File .\Install-RecBox.ps1 -FromGitHub -DesktopShortcut -Launch

Developers — build packages

powershell -ExecutionPolicy Bypass -File .\build-installer.ps1
Produces a versioned zip for Releases. If Inno Setup 6 is installed, also builds Setup.exe. For day-to-day coding use run.ps1.

Requirements

  • OS: Windows 10 or 11 (64-bit)
  • End users: no .NET SDK needed (self-contained build)
  • To build installers: .NET 8 SDK; optional Inno Setup 6 for Setup.exe
  • Optional: NVIDIA / AMD / Intel GPU for hardware encoding; NVIDIA Broadcast for mic

How to record

  1. Choose a monitor — native resolution is shown in the list.
  2. Microphone (optional) — Default, a specific device, or NVIDIA Broadcast.
  3. System audio (optional) — capture what your PC plays; independent from the mic.
  4. Quality — Low file size, Balanced, or Maximum quality.
  5. Press Start — the big teal control. Timer begins.
  6. Hide to tray — minimize or close so RecBox leaves the taskbar.
  7. Stop from the app or tray menu. Open folder to find your MP4.

System tray

Minimize or close the window to send RecBox to the tray (next to the clock). Recording continues in the background without appearing in the capture.

  • Double-click the tray icon to restore the window.
  • Right-click for Show, Start/Stop, or Exit.
  • Use Exit when you want to quit completely.

Troubleshooting

FFmpeg was not found

Run run.ps1 or tools/download-ffmpeg.ps1, or place ffmpeg.exe in tools/ffmpeg.

No microphone / NVIDIA Broadcast missing

Check Windows Sound settings. Install/enable NVIDIA Broadcast, then restart RecBox.

System audio silent or disabled

You need an active playback device (speakers/headphones) set as default. RecBox uses WASAPI loopback — no virtual cable needed.

Black screen in games

Try borderless windowed mode. Elevated windows may need RecBox run as Administrator.

Where are my files?

Default: %UserProfile%\Videos\RecBox. Use Open folder in the app.
